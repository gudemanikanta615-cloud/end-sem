# 4K HD Drawing Studio

A browser-based drawing demo built with HTML, CSS, and JavaScript. Open `index.html` in a modern browser to use it.

## Features

- Upload an image from your device.
- Create a drawing effect on a 4K canvas.
- Start, pause, and reset the drawing animation.
- Download the completed result as a PNG.

## Files

- `index.html` contains the drawing studio and its main JavaScript.
- `script.js` contains a color and font-size helper snippet. It is not currently loaded by `index.html`.

The page runs locally in the browser and does not upload images to a server.
